The idea

Bring the phones together.

The intended flow keeps pairing simple and moves files directly between devices, without an ANRO-operated cloud relay.

01

Tap to pair

NFC is designed to initiate the connection between compatible Android phones.

02

Connect directly

After pairing, the project uses Wi-Fi Direct as its intended transfer route.

03

Send device to device

Your files are intended to travel between the two phones, not through an ANRO file server.

What matters

Small project. Clear priorities.

No big-company promises. Just the principles behind ANRO-BEAM.

NFC pairing

Tap-based pairing is the core interaction, for devices with compatible NFC hardware.

Wi-Fi Direct

Designed to carry the file transfer after the initial pairing step. Internet access is not the goal.

No ANRO transfer server

The project is designed without an ANRO-operated server or cloud upload in the file path.

Open source · MIT

Read the code, inspect how it works, and review the MIT-licensed project on GitHub.

Built independently

Not a giant company. Just a project being built in public.

ANRO-BEAM is an indie project developed on a zero-budget setup. There is no ANRO-operated backend to maintain, and the project is shared openly so people can inspect its direction and progress.

0 ads promisedMIT licensedOpen development

Compatibility, honestly.

ANRO-BEAM is intended for compatible Android phones with NFC. Actual support depends on device hardware, Android version, permissions and app build. Testing so far is Samsung-heavy; other brands still need broader real-device testing.

Note: The website's interactive demo is a simulation. It does not send a real file.
